# Mini Task Board - Frontend 💻

This is the Next.js client for the **Mini Task Board Assessment**.

## Tech Stack
- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Library:** React 19
- **Styling:** Tailwind CSS
- **Language:** TypeScript

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Make sure the backend server is running on `http://localhost:5000`.

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build for Production

```bash
npm run build
npm start
```
